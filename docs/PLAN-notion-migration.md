## 구현 방향

### 카드 — DESIGN.md와의 충돌을 이렇게 푼다

`DESIGN.md` 는 카드를 금지한다("`rounded-2xl border bg-white` 블록을 다시 만들지 않는다"). 사용자가 카드를 명시적으로 요청했으므로 **금지의 의도를 지키면서 형태를 만든다.**

금지의 이유는 "떠 있는 표면"과 "AI가 만든 티"였지 이미지 타일 자체가 아니다. 따라서,

- 그림자 없음, 배경 채움 없음
- 1px 괘선으로만 경계
- 반경 2px (기존 잠금 그대로)
- 이미지 + 제목 + 기간 + 태그 + 대표 수치
- 호버에서 배경을 칠하지 않고 **제목만 액센트**

이러면 카드가 아니라 **"이미지가 붙은 사양서 행"** 이 된다. `DESIGN.md` 의 Components 절에 이 예외를 이유와 함께 적는다.

### 모달 — 접근성을 지킨다

`<dialog>` 엘리먼트를 쓴다. 직접 만든 오버레이보다 포커스 트랩과 `Esc` 를 브라우저가 처리해 준다.

- `showModal()` / `close()`
- 배경 스크롤 잠금
- 열릴 때 제목에 포커스, 닫으면 원래 카드로 복귀
- `aria-labelledby` 로 제목 연결
- 모바일에서는 전체 화면
- **URL을 바꾼다** (`?project=cs25`). 안 그러면 뒤로가기로 닫을 수 없고 링크 공유도 안 된다

본문은 마크다운이므로 블로그에서 쓴 것과 같은 방식으로 렌더한다. `react-markdown` 을 포트폴리오에도 추가해야 한다 (현재 미설치).

### 콘텐츠를 어디에 둘까

**정적 파일로 넣는다.** 노션 API를 런타임에 부르지 않는다.

- 포트폴리오는 자주 안 바뀐다
- 노션 이미지 URL 만료 문제를 매번 겪을 이유가 없다
- 빌드 의존성이 늘어나면 배포가 취약해진다

`content/projects/*.md` 에 frontmatter + 본문으로 두고, 빌드 때 읽는다. 노션이 정본이면 나중에 동기화 스크립트를 만들면 된다.

## 작업 순서

1. `docs/notion-source-*.md` 를 읽고 프로젝트 3건을 `content/projects/{cs25,hanghae99,monest-ai}.md` 로 정리 (frontmatter: 제목, 기간, 태그, 요약, 대표 수치, 이미지)
2. 이미지 최적화 (1.8MB → 200KB 목표, 필요하면 webp)
3. `react-markdown` + `remark-gfm` 설치
4. `components/ProjectCard.tsx` — 이미지 타일 행
5. `components/ProjectModal.tsx` — `<dialog>` + 마크다운 본문 + URL 동기화
6. `components/Projects.tsx` 교체
7. 히어로/소개에 **핵심 역량 3가지**와 **관심 분야** 반영, 포지셔닝 문구 검토
8. `DESIGN.md` 에 카드 예외와 모달 규칙 추가
9. `npm run build` + `impeccable detect` + 육안 확인 (다크/라이트/모바일)
10. 커밋 분할해서 push

## 미리 정해둘 것 (내일 물어볼 것)

- **포지셔닝 문구를 바꿀까?** 현재 "AI와 협업하는 백엔드 개발자" vs 노션 "팀 전체 생산성을 위해 항상 고민하는". 후자가 더 넓지만 전자가 더 뾰족하다.
- **기존 AI 협업 타임라인을 유지할까?** 노션에는 없는 섹션이다. 사이트만의 강점이라 유지를 권한다.
- **프로젝트 상세 분량.** 24,363자를 그대로 넣으면 모달이 매우 길다. 트러블슈팅 단위로 접거나(accordion), 요약 + "전체 보기"로 나눌지 정해야 한다.
